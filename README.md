# MSPaint-WebApp-Clone-light
A modern MS Paint clone built with vanilla HTML, CSS, and JS. It features a sleek UI with a functional ribbon, dark/light mode, and custom color picker. Tools include pencil, brushes (marker, airbrush), flood fill, text, and 10+ shapes. Supports undo/redo, canvas resizing, image cropping, and transparent selections. Save and open local files!
